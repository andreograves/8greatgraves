# 8greatgraves

Family website for the descendants of Freeman Graves and Eliza Price of Collins, Mississippi, and their eight children: the 8 Great Graves.

Static single page (`index.html`), served by GitHub Pages at https://8greatgraves.com (see `CNAME`).

## Go live
1. Merge to `main`.
2. Settings > Pages: Deploy from a branch, `main`, `/ (root)`. Confirm the custom domain reads `8greatgraves.com`.
3. DNS at the registrar: four A records on `@` (185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153) and a CNAME `www` to `andreograves.github.io`. Keep any MX and TXT records.
4. Once the domain resolves, tick Enforce HTTPS.
